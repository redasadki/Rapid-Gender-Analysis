# Input template

Fill in these fields before running the skill. Attach documents alongside.

```
EMERGENCY: [name and type of emergency]
LOCATION AND SCOPE: [affected area and communities]
AUDIENCE: [who will read and act on this document]
LANGUAGE: [language of the output document]
OTHER INPUTS: [additional context, earlier RGAs, background documents, sitreps]
CONSTRAINTS: [word count, distribution format (web / PDF / print / messaging), deadlines]
LOCAL INPUTS: [voice notes, WhatsApp summaries, call notes, or reports from women-led organisations, with their consent and preferred credit]
```

## Phase 2 inputs

- The Phase 1 evidence file.
- Operator corrections: claims to drop, sources to add, framing to change, local organisations to name and credit.

## Defaults when a field is empty

| Field | Default |
|---|---|
| Audience | Humanitarian coordinators and cluster leads |
| Language | Language of the request |
| Distribution format | PDF, with numbered references |
| Word count | 3,000 to 5,000 words |
