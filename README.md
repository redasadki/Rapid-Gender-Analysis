# Rapid Gender Analysis skill

A model-agnostic AI skill that produces a Rapid Gender Analysis (RGA) for a humanitarian emergency in two gated phases: a verified evidence base, then a standard RGA document. It applies the RGA rubric and decolonial feminist (dRGA) criteria developed by The Geneva Learning Foundation (TGLF).
